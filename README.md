**✈️ Airport Search Engine
Высокопроизводительное консольное Java-приложение для поиска и фильтрации данных аэропортов (JDK 11)**

Данный инструмент предназначен для мгновенной навигации по реестру аэропортов. Система способна обрабатывать огромные CSV-файлы, предоставляя пользователю молниеносный доступ к записям по названию и гибкую систему фильтрации по любому столбцу данных с использованием сложных логических выражений.

**🚀 Ключевые возможности**
⚡ Мгновенный доступ к данным:
Разработана надежная система индексации на базе коллекции TreeMap, обеспечивающая логарифмическую сложность поиска. Это гарантирует высокую скорость отклика при работе с большими объемами информации независимо от размера входного CSV-файла.

**🧠 Интеллектуальный парсинг фильтров:**
Реализован мощный механизм разбора пользовательских запросов. Для анализа сложных логических выражений (с поддержкой операторов сравнения =, <>, >, <, приоритетов операций и скобок) применяются регулярные выражения в связке с классическим алгоритмом обратной польской записи (RPN). Это позволяет гибко и точно обрабатывать критерии отбора по любому столбцу данных, объединяя их операторами & (И) и || (ИЛИ).

**🗂️ Оптимизация производительности:**
Внедрено кэширование результатов поиска с использованием WeakHashMap, что минимизирует накладные расходы при повторении идентичных запросов и способствует эффективному управлению памятью.

**📁 Источник данных**
Приложение функционирует на основе загружаемой таблицы аэропортов в формате CSV, где второй столбец (column[2]) резервируется под наименование узлового элемента поиска (название аэропорта). Содержимое остальных столбцов может быть любым и используется исключительно для применения фильтров.

*Для парсинга фильтра использовал регулярные выражения и [алгоритм обратной польской записи](https://ru.wikipedia.org/wiki/Обратная_польская_запись)*

*Для быстрого поиска по городам использовал TreeMap для индексирования строчек,бинарный поиск и [WeakHashMap](https://docs.oracle.com/en/java/javase/17/docs/api/java.base/java/util/WeakHashMap.html) для кэширования запросов*
